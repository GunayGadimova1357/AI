
# Что такое функция активации?

**Функция активации** — это математическая функция, которая применяется после вычисления

[
y = xW + b
]

Она определяет, **какой сигнал передать следующему слою**, и добавляет **нелинейность** в нейронную сеть.

Без функции активации даже очень глубокая нейронная сеть работала бы как обычная линейная модель.

---

# Основные функции активации

## 1. ReLU (Rectified Linear Unit)

**Формула:**

[
ReLU(x)=\max(0,x)
]

То есть:

```text
x = -3 → 0
x = -1 → 0
x = 2  → 2
x = 5  → 5
```

### Плюсы

* ✅ Очень быстрая.
* ✅ Не страдает от затухания градиента для положительных значений.
* ✅ Самая популярная функция для скрытых слоёв.

### Минусы

* ❌ Может возникнуть проблема **"умирающего ReLU"** — если нейрон постоянно получает отрицательные значения, его выход всегда будет 0, и он перестанет обучаться.

**Используется:** в скрытых слоях большинства современных нейронных сетей.

---

## 2. Sigmoid

**Формула:**

[
\sigma(x)=\frac1{1+e^{-x}}
]

Преобразует любое число в диапазон:

```text
0 ... 1
```

Например:

```text
-5 → 0.01
0 → 0.5
5 → 0.99
```

### Плюсы

* ✅ Выход можно интерпретировать как вероятность.
* ✅ Подходит для бинарной классификации.

### Минусы

* ❌ Подвержена **затуханию градиента**.
* ❌ Не центрирована относительно нуля (все значения положительные), из-за чего обучение может идти медленнее.

**Используется:** в выходном слое бинарной классификации.

---

## 3. Tanh

Преобразует число в диапазон

```text
-1 ... 1
```

Например:

```text
-5 → -0.99
0 → 0
5 → 0.99
```

### Плюсы

* ✅ Центрирована относительно нуля.
* ✅ Обычно обучается лучше, чем Sigmoid в скрытых слоях.

### Минусы

* ❌ Также страдает от затухания градиента.
* ❌ Используется реже, чем ReLU.

**Используется:** иногда в скрытых слоях и рекуррентных нейронных сетях (RNN).

---

## 4. Softmax

Преобразует **логиты** (оценки модели) в **вероятности**, сумма которых равна 1.

Например:

```text
Logits:
[2.5, 1.2, -0.8]

После Softmax:
[0.75, 0.20, 0.05]
```

### Плюсы

* ✅ Возвращает вероятности.
* ✅ Сумма вероятностей всегда равна 1.

### Минусы

* ❌ Используется только для выходного слоя при многоклассовой классификации.

**Используется:** в выходном слое многоклассовой классификации.

---

# Сравнение

| Функция     | Диапазон | Плюсы                                                      | Минусы                                                 | Где используется             |
| ----------- | -------- | ---------------------------------------------------------- | ------------------------------------------------------ | ---------------------------- |
| **ReLU**    | 0 … ∞    | Быстрая, не затухает градиент (для положительных значений) | Может возникнуть «умирающий ReLU»                      | Скрытые слои                 |
| **Sigmoid** | 0 … 1    | Возвращает вероятность                                     | Затухающий градиент, не центрирована относительно нуля | Выход бинарной классификации |
| **Tanh**    | −1 … 1   | Центрирована относительно нуля                             | Затухающий градиент                                    | Иногда скрытые слои, RNN     |
| **Softmax** | 0 … 1    | Вероятности по всем классам                                | Только для многоклассовой классификации                | Выходной слой                |

## Кратко

**Функция активации** — это функция, которая применяется после вычисления `xW + b`. Она делает нейронную сеть нелинейной, благодаря чему сеть может изучать сложные зависимости. На практике чаще всего используют **ReLU** в скрытых слоях, **Sigmoid** — в выходном слое для бинарной классификации, а **Softmax** — в выходном слое для многоклассовой классификации. **Tanh** применяется реже, но её преимущество в том, что она центрирована относительно нуля.

Запомнить
Затухающий градиент
Градиент становится всё меньше по мере прохождения через слои, из-за чего первые слои почти перестают обучаться.
Центрирована относительно нуля
Выход функции содержит как отрицательные, так и положительные значения (например, диапазон −1…1 у Tanh).


Xavier (Glorot) Initialization используется для функций активации Sigmoid и Tanh. Она подбирает начальные веса так, чтобы сигнал при прохождении через слои не становился слишком большим или слишком маленьким.
He (Kaiming) Initialization используется для ReLU и её вариантов. Поскольку ReLU обнуляет все отрицательные значения, инициализация Хе задаёт веса немного большего масштаба, чтобы компенсировать эту потерю сигнала и сохранить стабильное обучение.
