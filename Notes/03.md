### 1. Что такое Pandas?

Pandas — это популярная библиотека с открытым исходным кодом для языка программирования Python, предназначенная для быстрой обработки, очистки и глубокого анализа табличных данных и временных рядов.

---

- DataFrame -> полноценная таблица
- Series -> колонки (один столбец данных)
- read_csv() -> читать из файла(csv)
- head() -> показать первые 5(по умолчанию) или n строк данных
- tail() -> показать последние 5(по умолчанию) или n строк данных
- describe() -> просмотр данных таблицы (mean, std, min, 25%, 50%(median), 75%, max)
- iloc() -> получение строки по номеру позиции
- loc() -> получение строки по имени индекса

---

# 2. Что такое Series

Создаём данные:

```python
my_index = ["Azerbaijan", "Usa", "Canada", "UK"]
my_data = [85, 20, 65, 78]
```

---

## Создание Series

```python
my_series = pd.Series(my_data, index=my_index)
```

Получаем:

```python
Azerbaijan    85
Usa           20
Canada        65
UK            78
dtype: int64
```

Структура:

```python
индекс -> значение
```

Можно представить как словарь:

```python
{
 "Azerbaijan": 85,
 "Usa": 20,
 "Canada": 65,
 "UK": 78
}
```

---

## Доступ по индексу

```python
my_series["Azerbaijan"]
```

Результат:

```python
85
```

---

# 4. Операции между Series

Созданы два квартала продаж:

```python
sales_q1
```

```python
Japan     80
China    400
India    200
USA      250
```

---

```python
sales_q2
```

```python
China     500
Brazil    100
India     210
USA       250
```

---

## Получить индексы

```python
sales_q1.keys()
```

Результат:

```python
Index(['Japan', 'China', 'India', 'USA'])
```

---

## Умножение

```python
sales_q1 * 2
```

Получаем:

```python
Japan    160
China    800
India    400
USA      500
```

Каждое значение умножается на 2.

---

## Сложение Series

```python
sales_q1 + sales_q2
```

Результат:

```python
Brazil      NaN
China     900
India     410
Japan       NaN
USA       500
```

---

### Почему NaN?

* Japan есть только в Q1
* Brazil есть только в Q2

Pandas не знает что складывать.

Поэтому:

```python
NaN
```

(Not a Number)

---

## Решение через fill_value

```python
sales_q1.add(sales_q2, fill_value=0)
```

Результат:

```python
Brazil    100
China     900
India     410
Japan      80
USA       500
```

Отсутствующие значения заменяются на 0.

# 5. DataFrame

Создаём столбцы:

```python
my_columns = ["Jan", "Feb", "Mar"]
```

---

Создаём случайные данные:

```python
np.random.seed(42)
```

Матрица:

```python
[
```

# 16. describe()

Одна из самых полезных функций Pandas.

```python
employee_data_frame.describe()
```

Показывает статистику:

| Показатель | Значение               |
| ---------- | ---------------------- |
| count      | количество             |
| mean       | среднее                |
| std        | стандартное отклонение |
| min        | минимум                |
| 25%        | первый квартиль        |
| 50%        | медиана                |
| 75%        | третий квартиль        |
| max        | максимум               |

---

Например:

```python
Salary
```

| Показатель | Значение |
| ---------- | -------- |
| mean       | 72947    |
| min        | 30854    |
| max        | 119045   |

---

# 17. transpose()

```python
employee_data_frame.describe().transpose()
```

или

```python
employee_data_frame.describe().T
```

Меняет строки и столбцы местами.

Было:

```python
mean
min
max
```

по строкам.

Стало:

```python
Age
Salary
ExperienceYears
```

по строкам.

Так читать статистику обычно удобнее.
