### 1. Что такое Pandas?

Pandas — это популярная библиотека с открытым исходным кодом для языка программирования Python, предназначенная для быстрой обработки, очистки и глубокого анализа табличных данных и временных рядов.

---

- `DataFrame` -> полноценная таблица
- `Series` -> колонки (один столбец данных)
- `read_csv()` -> читать из файла(csv)
- `head()` -> показать первые 5(по умолчанию) или n строк данных
- `tail()` -> показать последние 5(по умолчанию) или n строк данных
- `describe()` -> просмотр данных таблицы (mean, std, min, 25%, 50%(median), 75%, max)
- `iloc()` -> получение строки по номеру позиции
- `loc()` -> получение строки по имени индекса

---

### 3. Что такое Series

Создаём данные:

```python
my_index = ["Azerbaijan", "Usa", "Canada", "UK"]
my_data = [85, 20, 65, 78]
```

---

#### Создание Series

```python
my_series = pd.Series(my_data, index=my_index)
```

Получаем:

```python
Azerbaijan    85
Usa           20
Canada        65
UK            78
dtype: int64
```

Структура:

```python
индекс -> значение
```

Можно представить как словарь:

```python
{
 "Azerbaijan": 85,
 "Usa": 20,
 "Canada": 65,
 "UK": 78
}
```

---

#### Доступ по индексу

```python
my_series["Azerbaijan"]
```

Результат:

```python
85
```

---

### 4. Создание Series из словаря

### 5. Операции между Series

Созданы два квартала продаж:

```python
sales_q1
```

```python
Japan     80
China    400
India    200
USA      250
```

---

```python
sales_q2
```

```python
China     500
Brazil    100
India     210
USA       250
```

---

#### Получить индексы

```python
sales_q1.keys()
```

Результат:

```python
Index(['Japan', 'China', 'India', 'USA'])
```

---

#### Умножение

```python
sales_q1 * 2
```

Получаем:

```python
Japan    160
China    800
India    400
USA      500
```

Каждое значение умножается на 2.

---

#### Сложение Series

```python
sales_q1 + sales_q2
```

Результат:

```python
Brazil      NaN
China     900
India     410
Japan       NaN
USA       500
```

---

##### Почему NaN?

* Japan есть только в Q1
* Brazil есть только в Q2

Pandas не знает что складывать.

Поэтому:

```python
NaN
```

(Not a Number)

---

#### Решение через fill_value

```python
sales_q1.add(sales_q2, fill_value=0)
```

Результат:

```python
Brazil    100
China     900
India     410
Japan      80
USA       500
```

Отсутствующие значения заменяются на 0.

### 18. transpose()

```python

```

```python

```

```python

```

по строкам.


по строкам.

Так читать статистику обычно удобнее.

## Часть 2. Выбор столбцов, удаление строк/колонок, форма таблицы, индексы, `loc` и `iloc`

### 1. Получить один столбец

```python
employee_data_frame["Country"]
```

Возвращает один столбец как **Series**:

```python
0            USA
1     Azerbaijan
2        Germany
...
Name: Country, Length: 100, dtype: str
```

То есть:

```python
df["column_name"]
```

возвращает **один столбец**.

---

### 2. Получить несколько столбцов

```python
employee_data_frame[["Country", "Name"]]
```

Возвращает **DataFrame** с двумя колонками:

| Country    | Name     |
| ---------- | -------- |
| USA        | Lucy     |
| Azerbaijan | Victoria |
| Germany    | Benjamin |

Важно: для нескольких колонок нужны **двойные квадратные скобки**:

```python
df[["col1", "col2"]]
```

---

### 3. drop()

```python
employee_data_frame.drop("Country", axis=1)
```

Удаляет колонку `Country`.

#### Что такое `axis`

| axis     | Значение |
| -------- | -------- |
| `axis=0` | строки   |
| `axis=1` | колонки  |

---

#### Удалить колонку

```python
employee_data_frame.drop("Country", axis=1)
```

Но оригинальная таблица **не изменилась**, потому что `inplace=False` по умолчанию.

Чтобы изменить оригинал:

```python
employee_data_frame.drop("Country", axis=1, inplace=True)
```

---

#### Удалить строку

```python
employee_data_frame.drop(0, axis=0)
```

Удаляет строку с индексом `0`.

Результат: было `100` строк, стало `99`.

---

### 4. shape

```python
employee_data_frame.shape
```

Результат:

```python
(100, 8)
```

Означает:

```python
100 строк, 8 колонок
```

### 5. set_index()

```python
employee_data_frame.set_index("Name", inplace=True)
```

Делает колонку `Name` новым индексом таблицы.

Было:

| index | Name     | Age |
| ----- | -------- | --- |
| 0     | Lucy     | 56  |
| 1     | Victoria | 46  |

Стало:

| Name     | Age |
| -------- | --- |
| Lucy     | 56  |
| Victoria | 46  |

Теперь `Name` больше не обычная колонка, а индекс.

---

### 6. loc[]

```python
employee_data_frame.loc["Zoe"]
```

`loc` ищет строку **по имени индекса**.

Так как индекс теперь `Name`, можно искать по имени сотрудника.

Результат:

```python
ID                      5
Age                    38
Country            Brazil
Salary              76717
ExperienceYears         5
Remote                Yes
Department         Design
Name: Zoe, dtype: object
```

То есть это данные сотрудника `Zoe`.

---

### 7. iloc[]

```python
employee_data_frame.iloc[5]
```

`iloc` ищет строку **по номеру позиции**.

Позиция `5` — шестая строка, потому что счёт начинается с нуля.

Результат:

```python
Name: Sebastian
ID                      6
Age                    56
Country             Japan
Salary             117092
ExperienceYears         5
Remote                Yes
Department         Design
```

---

### Главное отличие `loc` и `iloc`

| Команда  | Ищет по чему      | Пример          |
| -------- | ----------------- | --------------- |
| `loc[]`  | по имени индекса  | `df.loc["Zoe"]` |
| `iloc[]` | по номеру позиции | `df.iloc[5]`    |

Очень важно:

```python
df.loc["Zoe"]
```

ищет индекс с названием `"Zoe"`.

```python
df.iloc[5]
```

берёт шестую строку по порядку.

---

### Краткая шпаргалка

| Код                          | Что делает                  |
| ---------------------------- | --------------------------- |
| `df["Country"]`              | получить один столбец       |
| `df[["Country", "Name"]]`    | получить несколько столбцов |
| `df.drop("Country", axis=1)` | удалить колонку             |
| `df.drop(0, axis=0)`         | удалить строку              |
| `df.shape`                   | размер таблицы              |
| `df.set_index("Name")`       | сделать колонку индексом    |
| `df.loc["Zoe"]`              | строка по имени индекса     |
| `df.iloc[5]`                 | строка по номеру позиции    |
