# Decision tree - Дерево решений

Дерево решений (Decision tree) — это метод поддержки принятия решений и алгоритм машинного обучения, который представляет данные или бизнес-процесс в виде иерархической древовидной структуры. Алгоритм работает по принципу последовательных правил «Если <условие>, то <результат>», разделяя массив данных на более мелкие группы.

Структура дерева решенийВизуально модель состоит из узлов трех типов, напоминающих перевернутое дерево:
- Корневой узел (Root Node): Самый первый вопрос или параметр, с которого начинается разделение данных.
- Ветви (Branches): Пути или стрелки, соединяющие узлы, которые представляют варианты развития событий или ответы на условия.
- Листья (Leaf Nodes / Терминальные узлы): Конечные точки дерева, которые содержат окончательный прогноз, класс или принятое решение.

Само по себе дерево решений (Decision Tree) — это отдельный базовый алгоритм машинного обучения, а не ансамбль. Однако деревья решений являются основой для мощных ансамблевых методов (таких как случайный лес или градиентный бустинг), где множество деревьев объединяются для улучшения точности.

```python
reg = DecisionTreeRegressor(criterion="squared_error", random_state=42)
```
Создаётся модель дерева решений для регрессии.

```python 
param_grid = {
    "tree__max_depth": [3, 5, 7, None],
    "tree__min_samples_split": [2, 5, 10],
    "tree__min_samples_leaf": [1, 3, 5, 10]
}
```
Это список параметров, которые будут проверяться.
- max_depth — максимальная глубина дерева;
- min_samples_split — минимум объектов для разделения узла;
- min_samples_leaf — минимум объектов в листе дерева.

## Random Forest

**Random Forest (Случайный лес)** — это множество деревьев решений, которые работают вместе.

**Как работает:**

1. Строится много деревьев (например, 100).
2. Каждое дерево обучается на случайной части данных.
3. Каждое дерево делает прогноз.
4. Итоговый ответ — среднее значение прогнозов всех деревьев.

Для регрессии:

```text
Дерево 1 → 45000
Дерево 2 → 47000
Дерево 3 → 43000

Итог:
(45000 + 47000 + 43000) / 3 = 45000
```

### Плюсы

* Точнее, чем одно дерево.
* Меньше переобучается.
* Более устойчив к ошибкам в данных.

### Минусы

* Медленнее обучается.
* Сложнее объяснить результат.

### Код

```python
from sklearn.ensemble import RandomForestRegressor

reg = RandomForestRegressor(
    n_estimators=100,
    random_state=42
)
```
## Gradient Boosting

**Gradient Boosting** — это алгоритм, который строит деревья **последовательно**.

Идея:

1. Первое дерево делает прогноз.
2. Находятся ошибки.
3. Следующее дерево пытается исправить эти ошибки.
4. Процесс повторяется много раз.

```text
Дерево 1 → ошибка
Дерево 2 → исправляет ошибку
Дерево 3 → исправляет оставшуюся ошибку
...
```

### Код

```python
from sklearn.ensemble import GradientBoostingRegressor

reg = GradientBoostingRegressor(
    n_estimators=100,
    learning_rate=0.1,
    random_state=42
)
```

### Плюсы

* Высокая точность
* Хорошо работает на табличных данных

### Минусы

* Дольше обучается
* Легче переобучается при неправильных настройках

## Запомнить

* **Decision Tree** = 1 дерево.
* **Random Forest** = много независимых деревьев.
* **Gradient Boosting** = каждое новое дерево исправляет ошибки предыдущих.
