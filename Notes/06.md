## EDA (Exploratory Data Analysis)

EDA (Exploratory Data Analysis) — это предварительное исследование датасета для выявления его структуры, основных характеристик, аномалий и скрытых закономерностей. Это фундамент любого проекта по анализу данных или машинному обучению, который позволяет «услышать» данные до построения сложных математических моделей. Термин был введен Джоном Тьюки в 1970-х годах.

До предобработки мы анализируем данные. 

Это базовые методы для первичного анализа данных:

## One-Hot Encoding (One-hot кодирование)

Проблема факторизации:

Для модели получается:

```python
yes = 0
no = 1
```

и она может подумать, что

```python
1 > 0
```

то есть между категориями есть порядок.

Для категорий это неверно.

---

### Решение

```python
pd.get_dummies()
```

---

```python
data_onehot = pd.get_dummies(
    data_factorized,
    columns=categorial_cols,
    drop_first=True
)
```

Создаются новые бинарные столбцы.

Например:

```python
driveway
```

превращается в

```python
driveway_1
```

где

```python
False = yes
True = no
```

---

### Почему `drop_first=True`

Без него были бы:

```python
driveway_0
driveway_1
```

Один столбец лишний.

Поскольку

```python
driveway_0 = 1 - driveway_1
```

модель может столкнуться с мультиколлинеарностью.

Поэтому один столбец удаляется.

### MinMaxScaler

```python
MinMaxScaler()
```

Формула:

$$
x'=\frac{x-min}{max-min}
$$

---

Пример:

Если

```python
lotsize
```

от

```python
1650 до 16200
```

то значение

```python
5850
```

станет

```python
0.288
```

---

После преобразования:

Все значения лежат в диапазоне

```python
[0;1]
```

---

### StandardScaler

```python
StandardScaler()
```

Формула:

[
x'=\frac{x-\mu}{\sigma}
]

где

* μ — среднее
* σ — стандартное отклонение

---

После масштабирования:

Среднее:

```python
0
```

Стандартное отклонение:

```python
1
```

---

Например

```python
0.323
```

означает:

> значение выше среднего на 0.323 стандартных отклонения

# 5. Заполнение пропусков (Imputation)

## Для чисел

```python
SimpleImputer(strategy="median")
```

Заполняет медианой.

Например:

```python
[10,20,30,NaN]
```

↓

```python
[10,20,30,20]
```

---

Почему медиана?

Она устойчива к выбросам.

---

## Для категорий

```python
SimpleImputer(strategy="most_frequent")
```

Заполняет самым частым значением.

Например:

```python
yes yes yes no NaN
```

↓

```python
yes yes yes no yes
```

---

После:

```python
data_impute_demo.isna().sum()
```

получаем:

```python
0
```

во всех столбцах.

# 13. Learning Curve

```python
learning_curve(...)
```

Строит кривую обучения.

Показывает:

* как растёт качество при увеличении данных;
* есть ли переобучение;
* есть ли недообучение.

---

```python
train_mean
```

Качество на обучающей выборке.

---

```python
test_mean
```

Качество на кросс-валидации.

---

Если линии:

* близко друг к другу → модель хорошо обобщает;
* далеко → переобучение;
* обе низкие → недообучение.

Для вашей линейной регрессии по R² ≈ 0.62 ожидаемо увидеть, что кривые сходятся примерно в диапазоне **0.55–0.65**, что говорит о том, что модель ограничена своей простотой и для существенного улучшения могут понадобиться более сложные модели (например, Random Forest или Gradient Boosting).
