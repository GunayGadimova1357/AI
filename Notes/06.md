## EDA (Exploratory Data Analysis)

EDA (Exploratory Data Analysis) — это предварительное исследование датасета для выявления его структуры, основных характеристик, аномалий и скрытых закономерностей. Это фундамент любого проекта по анализу данных или машинному обучению, который позволяет «услышать» данные до построения сложных математических моделей. Термин был введен Джоном Тьюки в 1970-х годах.

До предобработки мы анализируем данные. 

Сюда входит:

# `data.head()`

Показывает первые 5 строк таблицы.

```python
data.head()
```

Нужно, чтобы быстро понять:

* какие есть колонки;
* как выглядят данные;
* какие значения встречаются;
* есть ли текстовые признаки, например `yes/no`.

---

# `data.shape`

Показывает размер таблицы:

```python
data.shape
```

Результат:

```python
(546, 13)
```

Это значит:

* `546` строк — наблюдений, домов;
* `13` столбцов — признаков.

---

# `data.dtypes`

Показывает тип данных в каждом столбце:

```python
data.dtypes
```

Например:

```python
price       int64
driveway      str
```

Значит:

* `int64` — числовой столбец;
* `str` — текстовый столбец.

Это важно перед моделированием: текстовые признаки вроде `yes/no` часто нужно преобразовать в числа.

---

# `data.isna().sum()`

Проверяет пропущенные значения:

```python
data.isna().sum()
```

Везде `0`, значит пропусков нет.

Например:

```python
price    0
lotsize  0
```

означает, что в `price` и `lotsize` нет пустых значений.

---

# `data.describe()`

Даёт статистическое описание числовых колонок:

```python
data.describe()
```

Показывает:

* `count` — количество значений;
* `mean` — среднее;
* `std` — стандартное отклонение;
* `min` — минимум;
* `25%` — первый квартиль;
* `50%` — медиана;
* `75%` — третий квартиль;
* `max` — максимум.

Например для `price`:

```python
mean = 68121.6
min = 25000
max = 190000
```

То есть средняя цена дома около `68 122`, минимальная `25 000`, максимальная `190 000`.

# Гистограмма цены

```python
plt.figure()
plt.hist(data["price"], bins=30)
plt.title("Распределение цены")
plt.xlabel("Price")
plt.ylabel("Count")
plt.show()
```

Этот код строит гистограмму цен.

Что делает каждая строка:

```python
plt.figure()
```

Создаёт новую область для графика.

```python
plt.hist(data["price"], bins=30)
```

Строит гистограмму по столбцу `price`.
`bins=30` означает, что цены будут разбиты на 30 интервалов.

```python
plt.title("Распределение цены")
```

Добавляет заголовок.

```python
plt.xlabel("Price")
plt.ylabel("Count")
```

Подписывает оси:

* `Price` — цена;
* `Count` — количество домов.

```python
plt.show()
```

Показывает график.

Гистограмма помогает понять, как распределены цены: где больше всего домов, есть ли дорогие выбросы, симметрично ли распределение.
