### 1. Что такое matplotlib.pyplot?

Matplotlib — это популярная библиотека с открытым исходным кодом на языке программирования Python, предназначенная для визуализации данных двумерной (2D) и трехмерной (3D) графикой. Название является сокращением, отражающим ее изначальную цель: она создавалась как аналог команд построения графиков из среды MATLAB.

matplotlib.pyplot — это процедурный интерфейс (модуль) библиотеки Matplotlib, который предоставляет набор командных функций для быстрого и удобного создания двумерных графиков, гистограмм и диаграмм.

---

## 1. Базовый (функциональный) метод создания графиков

Самый простой способ быстро построить график с помощью `plt.plot()`.

```python
plt.plot(x, y)
plt.title("First plot") # Заголовок
plt.xlabel("x")         # Подпись оси X
plt.ylabel("y")         # Подпись оси Y
plt.xlim(0, 8)          # Ограничение оси X от 0 до 8
plt.ylim(0, 16)         # Ограничение оси Y от 0 до 16
plt.savefig("plot.png") # Сохранение графика в файл
plt.show()              # Вывод графика на экран

```

* **Главное:** Этот метод хорош для быстрых набросков, но не очень удобен, если на одном холсте нужно расположить несколько независимых графиков.

---

## 2. Объектно-ориентированный подход (ОП)

Здесь мы явно создаем объект «холста» (`fig`) и объект «осей» (`axes`), внутри которых рисуем. Это стандарт для сложной визуализации.

```python
fig = plt.figure() # Создаем пустой холст (фигуру)
# Добавляем оси: [отступ_слева, отступ_снизу, ширина, высота] в долях от 0 до 1
axes = fig.add_axes([0, 0, 1, 1]) 
axes.plot(x, y)

```

---

## 3. Вложенные графики (График в графике)

Используя координаты `add_axes`, можно вставлять один график внутрь другого.

```python
fig = plt.figure()

# Главный (большой) график на весь холст
axes1 = fig.add_axes([0, 0, 1, 1])
axes1.plot(a, b)

# Маленький график внутри большого
# Начинается с середины (0.5, 0.5) и занимает 50% ширины и высоты холста
axes2 = fig.add_axes([0.5, 0.5, 0.5, 0.5])
axes2.plot(x, y)

```

---

## 4. Сетки графиков (`plt.subplots`)

Вместо ручного высчитывания координат через `add_axes`, можно автоматически разбить холст на сетку (строки и столбцы). Функция возвращает кортеж: саму фигуру `fig` и массив осей `axes`.

### Пример 1: Одна строка, два столбца (1D массив осей)

```python
fig, axes = plt.subplots(nrows=1, ncols=2)
axes[0].plot(x, y) # Первый график (левый)
axes[1].plot(a, b) # Второй график (правый)
plt.tight_layout() # Автоматически подгоняет отступы, чтобы подписи не накладывались

```

### Пример 2: Сетка 2х2 (2D массив осей)

```python
fig, axes = plt.subplots(nrows=2, ncols=2)
axes[0, 0].plot(x, y) # Верхний левый график
axes[1, 0].plot(a, b) # Нижний левый график
plt.tight_layout()

```

## 5. Стилизация, цвета и легенда

```python
fig = plt.figure()
axes = fig.add_axes([0, 0, 1, 1])

# lw (или linewidth) — толщина линии. По умолчанию она равна 1. lw=8 делает линию очень толстой.
# color — можно задавать словом ('blue', 'red') или HEX-кодом ('#e00dcb')
axes.plot(x, y, label="y=2x", color="#e00dcb")
axes.plot(x, x**2, label="y=x**2", color="blue")
axes.plot(x, x+2, label="y=x+2", color="red", lw=8)

# Добавление легенды (использует текст из параметров label)
axes.legend(loc="upper right") # loc="upper right" принудительно ставит легенду в верхний правый угол

# Альтернатива: axes.legend(loc=(0, 0.25)) — точное позиционирование легенды по координатам
plt.show()

```

## 1. Базовая круговая диаграмма

Самый простой вариант. Автоматически делит круг на части на основе переданных значений и подписывает их.

```python
labels = ["Sumqayit", "Xirdalan", "Baltika"]
percents = [100, 40, 9]

plt.pie(percents, labels=labels)
plt.title("Pie diagram")
plt.show()

```

---

## 2. Добавление процентов внутрь секторов (`autopct`)

Чтобы диаграмма стала информативной, внутри долек обычно отображают их реальное процентное соотношение.

```python
plt.pie(percents, labels=labels, autopct="%1.2f%%")
plt.title("Pie diagram")
plt.show()

```

* **`autopct="%1.2f%%"`**: Это строка форматирования String Formatting в Python.
* `%1.2f` означает, что проценты будут отображаться как число с плавающей точкой с **двумя знаками после запятой** (например, `67.11%`).
* `%%` на конце просто рисует физический знак процента `%` на графике.



---

## 3. Продвинутая кастомизация (Взрыв, тени, поворот и цвета)

Превращает стандартный график в презентабельный элемент отчета.

```python
# 0 — оставить на месте, 0.1 — отнять (выдвинуть) дольку от центра на 10% от радиуса
explode = (0, 0.1, 0) 

plt.pie(
    percents, 
    labels=labels, 
    explode=explode,          # Выделяет (отодвигает) вторую дольку ("Xirdalan")
    autopct="%1.2f%%", 
    startangle=90,            # Поворачивает начало построения диаграммы на 90 градусов (вертикально вверх)
    shadow=True,              # Добавляет красивую объемную тень под график
    colors=["red", "green", "blue"] # Принудительно задает цвета для каждой дольки
)
plt.title("Pie diagram")
plt.show()

```

## 1. Базовый скаттер-плот (Точечный график)

 **скаттер-плот (диаграммами рассеяния / Scatter plots)** с помощью функции `plt.scatter()`. Этот тип графиков используется для визуализации отдельных точек данных и выявления зависимостей между ними.


Самый простой вариант: передаются два списка одинаковой длины (координаты $X$ и $Y$). На пересечении этих координат ставятся стандартные точки.

```python
x = [23, 66, 78, 1, 99, 7]
y = [69, 96, 0, 11, 19, 71]

plt.scatter(x, y)
plt.show()

```

---

## 2. Продвинутая визуализация (Цветовые карты, размеры и прозрачность)

Скаттер-плоты уникальны тем, что каждой отдельной точке можно задать свой **размер** и свой **цвет**. Это позволяет отобразить на плоском графике сразу до 4-х измерений данных: координаты $X$, координаты $Y$, размер точки (величина) и цвет точки (категория или интенсивность).

```python
x = np.random.random(100)       # 100 случайных чисел для оси X
y = np.random.random(100)       # 100 случайных чисел для оси Y
colors = np.random.random(100)  # Спектр чисел от 0 до 1 для окрашивания каждой точки
sizes = 500 * np.random.random(100) # Размеры точек (максимум до 500)

plt.scatter(
    x, y, 
    c=colors,         # Параметр c (color) принимает массив чисел для градиента
    s=sizes,          # Параметр s (size) задает размер каждой точки индивидуально
    alpha=0.8,        # Прозрачность точек (от 0 — невидимый, до 1 — плотный цвет)
    cmap="inferno"    # Цветовая схема (в данном случае "inferno" — огненный градиент)
)
plt.show()

```

## 3. Наложение графиков, маркеры и легенда

Здесь показано, как на одном холсте совместить два разных набора точек, изменить форму самих точек (маркеры) и добавить легенду.

```python
# Первый набор данных: маркер в виде крестика ("x"), цвет красный
plt.scatter(x, y, color="red", label="red", marker="x")

# Второй набор данных: меняем x и y местами, маркер в виде звездочки ("*"), 
# цвет синий, а размер точек берется из массива sizes
plt.scatter(y, x, color="blue", label="blue", marker="*", s=sizes)

plt.legend() # Выводит легенду (использует текст из label)
plt.show()

```

## 1. Вертикальная столбчатая диаграмма (`plt.bar`)

Классический график, где категории расположены на оси $X$, а значения — на оси $Y$.

```python
languages = ["Gyurgyshtan", "Nemes", "Fena", "Flomaster"]
words = [10, 15, 25, 2]

# Рисуем вертикальные столбцы красного цвета (#FF0000)
plt.bar(languages, words, color="#FF0000")

plt.xlabel("Language")
plt.ylabel("Words")
plt.title("World language-words diagram")
plt.show()

```

---

## 2. Горизонтальная диаграмма (`plt.barh`) с подписями данных

Использование `plt.barh()` разворачивает график на 90 градусов. Категории уходят на ось $Y$, а значения — на ось $X$. Это особенно удобно, если названия категорий слишком длинные и на вертикальном графике накладывались бы друг на друга.

В коде также есть попытка автоматически подписать числовое значение каждого столбца с помощью `plt.text()`.

```python
# Рисуем горизонтальные столбцы (bar + h = horizontal)
# Передаем список цветов, чтобы каждый столбец был своего цвета
plt.barh(languages, words, color=["#0054dd", "red", "blue", "orange"])

plt.xlabel("Language") # Внимание: при barh логичнее поменять подписи осей местами
plt.ylabel("Words")     # так как Words теперь на оси X, а Language — на оси Y
plt.title("World language-words diagram")

# Цикл для добавления текстовых значений на график
for i, value in enumerate(words):
    # plt.text(координата_X, координата_Y, сам_текст, ha="выравнивание")
    plt.text(i, i+0.4, str(value), ha="left") 
    
plt.show()

```
