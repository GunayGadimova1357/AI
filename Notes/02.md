## 1. Что такое Jupyter Notebook?

Jupyter Notebook — это интерактивная веб-среда разработки, которая позволяет объединять в одном документе (блокноте) исполняемый код, текст, графики, формулы и мультимедиа. В отличие от классических программ, где код выполняется сразу от начала и до конца, в Jupyter Notebook он делится на отдельные блоки — ячейки (cells).

---

## 2. Что такое Markdown?

Markdown — это популярный и интуитивно понятный язык облегченной разметки. Он позволяет оформлять текст (делать его жирным, создавать заголовки, списки, таблицы) прямо в обычном «Блокноте» или чате с помощью простых символов с клавиатуры, без сложных инструментов вроде Word.

---

# Ключевые элементы синтаксиса Markdown

## 1. Заголовки

Заголовки создаются с помощью символа `#` в начале строки.

```markdown
# Заголовок 1 уровня
## Заголовок 2 уровня
### Заголовок 3 уровня
#### Заголовок 4 уровня
##### Заголовок 5 уровня
###### Заголовок 6 уровня
```

Чем больше символов `#`, тем меньше уровень заголовка.

---

## 2. Жирный текст

Жирный текст выделяется двумя звездочками или двумя нижними подчеркиваниями.

```markdown
**Жирный текст**

__Жирный текст__
```

---

## 3. Курсив

Курсив выделяется одной звездочкой или одним нижним подчеркиванием.

```markdown
*Курсивный текст*

_Курсивный текст_
```

---

## 4. Жирный курсив

Жирный курсив создается с помощью трех звездочек или трех нижних подчеркиваний.

```markdown
***Жирный курсив***

___Жирный курсив___
```

---

## 5. Перечеркнутый текст

Перечеркнутый текст создается с помощью двух тильд `~~`.

```markdown
~~Перечеркнутый текст~~
```

---

## 6. Маркированный список

Маркированный список можно создавать с помощью `-`, `*` или `+`.

```markdown
- Первый пункт
- Второй пункт
- Третий пункт
```

```markdown
* Первый пункт
* Второй пункт
* Третий пункт
```

```markdown
+ Первый пункт
+ Второй пункт
+ Третий пункт
```

---

## 7. Нумерованный список

Нумерованный список создается с помощью цифры и точки.

```markdown
1. Первый пункт
2. Второй пункт
3. Третий пункт
```

---

## 8. Вложенный список

Вложенный список создается с помощью отступов.

```markdown
- Основной пункт
  - Вложенный пункт
    - Еще один вложенный пункт
- Следующий основной пункт
```

---

## 9. Список задач

Список задач создается с помощью `- [ ]` и `- [x]`.

```markdown
- [x] Выполненная задача
- [ ] Невыполненная задача
- [ ] Еще одна задача
```

---

## 10. Ссылки

Ссылка записывается в таком формате:

```markdown
[Название ссылки](https://google.com)
```

Пример:

```markdown
[Google](https://google.com)
```

---

## 11. Ссылка с подсказкой

Можно добавить текст, который появляется при наведении на ссылку.

```markdown
[Google](https://google.com "Открыть Google")
```

---

## 12. Автоматическая ссылка

Если нужно просто показать ссылку, можно использовать угловые скобки.

```markdown
<https://google.com>
```

---

## 13. Изображение

Изображение добавляется почти как ссылка, но перед квадратными скобками ставится `!`.

```markdown
![Описание картинки](image.png)
```

Пример:

```markdown
![Логотип](logo.png)
```

---

## 14. Изображение с ссылкой

Картинку можно сделать кликабельной.

```markdown
[![Описание картинки](image.png)](https://example.com)
```

---

## 15. Код в строке

Короткий код внутри текста пишется через обратные кавычки.

```markdown
Команда `print("Hello World")` выводит текст на экран.
```

---

## 16. Блок кода

Для большого блока кода используются три обратные кавычки.

````text
```python
print("Hello World")
```
`````

---

## 17. Блок кода с подсветкой синтаксиса

После первых трех обратных кавычек можно указать язык программирования.

````text
```javascript
console.log("Hello World");
```
````

Примеры языков:

````text
```html
<h1>Hello</h1>
```

```css
body {
  background: white;
}
```

```sql
SELECT * FROM users;
```

```bash
npm install
```
````

---

## 18. Цитата

Цитата создается с помощью символа `>`.

```markdown
> Это пример цитаты.
```

---

## 19. Многострочная цитата

```markdown
> Это первая строка цитаты.
> Это вторая строка цитаты.
> Это третья строка цитаты.
```

---

## 20. Вложенная цитата

```markdown
> Основная цитата
>> Вложенная цитата
>>> Еще более глубокая цитата
```

---

## 21. Горизонтальная линия

Горизонтальная линия создается с помощью трех дефисов, звездочек или нижних подчеркиваний.

```markdown
---

***

___
```

---

## 22. Таблица

Таблица создается с помощью вертикальных линий `|` и дефисов `-`.

```markdown
| Имя | Возраст | Город |
|-----|---------|-------|
| Али | 20 | Баку |
| Анна | 22 | Москва |
| Иван | 19 | Санкт-Петербург |
```

---

## 23. Выравнивание в таблице

В таблицах можно выравнивать текст.

```markdown
| Слева | По центру | Справа |
|:------|:---------:|-------:|
| текст | текст | текст |
| 100 | 200 | 300 |
```

Обозначения:

| Синтаксис | Значение               |
| --------- | ---------------------- |
| `:---`    | выравнивание слева     |
| `:---:`   | выравнивание по центру |
| `---:`    | выравнивание справа    |

---

## 24. Формула в строке

Формула внутри строки пишется через одинарные знаки доллара.

```markdown
Формула энергии: $E = mc^2$
```

---

## 25. Блок формулы

Отдельная формула пишется через двойные знаки доллара.

```markdown
$$
a^2 + b^2 = c^2
$$
```

---


```markdown

```

```markdown
$$
\sum_{i=1}^{n} x_i
$$
```


---

## 27. Экранирование символов

Если нужно показать специальный символ Markdown как обычный текст, перед ним ставится обратный слэш `\`.

```markdown
\# Это не заголовок

\*Это не курсив\*

\**Это не жирный текст\**

\[Это не ссылка\](https://google.com)
```

---

## 28. Перенос строки

Обычный перенос строки в Markdown не всегда создает новую строку.

Для переноса строки можно поставить два пробела в конце строки или использовать `<br>`.

```markdown
Первая строка  
Вторая строка
```

```markdown
Первая строка<br>
Вторая строка
```

---

## 29. Абзацы

Чтобы создать новый абзац, нужно оставить пустую строку между частями текста.

```markdown
Это первый абзац.

Это второй абзац.
```

---

## 30. HTML внутри Markdown

Во многих редакторах Markdown можно использовать HTML-теги.

```markdown
<b>Жирный текст через HTML</b>

<i>Курсив через HTML</i>

<u>Подчеркнутый текст</u>

<br>
```

---

## 31. Подчеркнутый текст

В обычном Markdown нет отдельного стандартного синтаксиса для подчеркивания, но можно использовать HTML.

```markdown
<u>Подчеркнутый текст</u>
```

---

## 32. Цветной текст

Цветной текст можно сделать через HTML, если редактор это поддерживает.

```markdown
<span style="color:red">Красный текст</span>

<span style="color:blue">Синий текст</span>
```

Не все Markdown-редакторы поддерживают стили.

---

## 33. Комментарии

Комментарии можно писать через HTML. Они не отображаются в готовом документе.

```markdown
<!-- Это комментарий, он не будет виден в документе -->
```

---

## 34. Сноски

Сноски поддерживаются не во всех редакторах, но часто работают в GitHub Markdown и Obsidian.

```markdown
Это текст со сноской[^1].

[^1]: Это объяснение сноски.
```

---

## 35. Ссылки-сноски

Ссылку можно вынести отдельно внизу документа.

```markdown
Это ссылка на [Google][1].

[1]: https://google.com
```

---

## 36. Комбинирование форматирования

Можно комбинировать разные способы оформления.

```markdown
**Жирный и _курсивный_ текст**

***Жирный курсив***

~~**Перечеркнутый жирный текст**~~

`код` внутри обычного текста
```

---

## 37. Блоки заметок

В GitHub Markdown можно использовать специальные блоки заметок.

```markdown
> [!NOTE]
> Это обычная заметка.

> [!TIP]
> Это полезный совет.

> [!IMPORTANT]
> Это важная информация.

> [!WARNING]
> Это предупреждение.

> [!CAUTION]
> Это осторожное предупреждение.
```

---
